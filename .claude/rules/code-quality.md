# 代码质量规则

- 不重复造轮子：多处相似逻辑提取为共用函数，新功能优先复用已有 helper。
- 不过度工程化：只做当前需求，不为假设的未来需求提前设计。
- UI 跨线程更新必须通过 `pyqtSignal`，禁止在非主线程直接操作 Qt 组件。
- 并发安全：不得在并发路径上用实例变量传递请求上下文。
- AI 输出可靠性：遇到 AI 输出格式不稳定（JSON 解析频繁失败、字段缺失、值越界）时，**优先考虑改用 tool_use + enum 约束**，而不是在 prompt 里加更多 JSON 格式限制。工具参数有 schema 强制约束，比自然语言指令可靠得多。
