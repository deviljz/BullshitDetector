# 使用说明

---

## 快捷键一览

| 快捷键 | 功能 |
|--------|------|
| `Alt+Q` | 截图分析 |
| `Alt+V` | 图片分析（读取剪贴板）|
| `Alt+T` | 文字/链接分析 |

---

## 截图分析（Alt+Q）

1. 按 `Alt+Q` 唤起全屏遮罩
2. 按住左键拖拽框选目标内容（聊天截图、新闻、朋友圈等）
3. 松手后弹出预览窗，选择模式：

| 按钮 | 说明 | 是否联网 |
|------|------|----------|
| 📝 总结 | 快速提炼核心要点，外文自动翻译为中文 | 🔄 按需 |
| ❓ 解释 | 识别角色/梗/术语，一句话直接回答 | 🔄 按需 |
| 🎬 求出处 | 识别截图来自哪部动漫/漫画/影视/游戏 | ✅ |
| 🔍 鉴屎官 | 联网核查真实性，给出扯淡指数 + 破绽分析 | ✅ |

4. 右下角出现加载动画，分析完毕后弹出结果卡片

---

## 图片分析（Alt+V）

1. 复制任意图片到剪贴板（截图、保存的图片均可）
2. 按 `Alt+V`，自动读取剪贴板，或在弹窗中手动拖拽文件
3. 选择模式后开始分析（支持同截图分析的所有模式）

---

## 文字/链接分析（Alt+T）

1. 按 `Alt+T` 或右键托盘 → 文字/链接分析
2. 粘贴文章正文、链接或描述文字
3. 选择模式（总结/解释/鉴屎官/求出处）

**支持直接粘贴链接自动抓取正文：**

| 来源 | 示例 | 说明 |
|------|------|------|
| 今日头条 | `toutiao.com/article/...` 或 `toutiao.com/w/...` | 自动抓取正文 + 文章配图（过滤头像/广告图）|
| 微信公众号 | `mp.weixin.qq.com/s/...` | 自动抓取正文 |
| 其他网页 | 任意 `http://` 或 `https://` 链接 | 尝试抓取正文，不含图片 |

> 头条链接抓取需要 Playwright（安装时已自动配置），首次抓取约需 15 秒。
> 微信公众号链接可直接分享，无需登录。

## 🎬 求出处

识别截图来自哪部作品，支持动漫、漫画、影视、游戏等。

**工作原理：**
1. AI 先用视觉识别图中的视觉特征、文字、风格
2. 若配置了 Google Vision API Key，自动调用以图搜图辅助确认
3. 综合所有信息输出：作品名、媒体类型、集数/章节、场景、角色

**结果页面：**
- 橙色卡片显示识别结果和置信度
- 若找到对比图片，会并排显示供比对

**提升准确率：**
配置 `google_vision_api_key`（免费 1000 次/月），以图搜图对冷门作品效果显著。详见 [API_KEYS.md](API_KEYS.md)。

## 托盘菜单

右键系统托盘图标（💩）：

- **截图分析** — 同 `Alt+Q`
- **图片分析** — 同 `Alt+V`
- **文字/链接分析** — 同 `Alt+T`
- **搜索引擎** — 切换 DuckDuckGo / Tavily
- **鉴屎官模式** — 经典（快速）/ 分阶段（更准确，见下方说明）
- **回复风格** — 毒舌讽刺 / 专业严肃 / 幽默风趣 / 简洁直白
- **退出** — 关闭程序

---

## 🔍 鉴屎官模式说明

托盘菜单 → 鉴屎官模式，可在两种核查路径间切换：

| 模式 | 速度 | 原理 | 适用场景 |
|------|------|------|---------|
| **经典**（默认）| 快（~15s）| 单轮 ReAct：边搜索边推理，结果注入同一上下文 | 日常快速核查 |
| **分阶段** | 稍慢（~20s）| 声明提取 → 各声明独立并行核查 → 反思层 → 汇总 | 复杂文章、数据混淆、需要高准确度 |

**分阶段模式的优势：**
- 每条声明用独立上下文搜索，互不干扰，避免"锚定效应"（搜到第一条结果就固化结论）
- 加入反思层，自动判断是否需要追加核查
- 图片只在第一阶段发送一次，节省 token

**注意：** 分阶段模式 API 调用次数约为经典的 2-3 倍，使用 Gemini 免费层时建议保持经典模式，高频测试时尤其注意。

## 搜索引擎切换

鉴屎官模式需联网搜索核实声明，支持两种引擎：

| 引擎 | 国内可用 | 配置 |
|------|---------|------|
| **DuckDuckGo**（默认）| ❌ 需要代理/VPN | 无需 Key |
| **Tavily** | ✅ 直连可用 | 需 API Key，免费 1000 次/月 |
| **Serper Google** | ✅ 直连可用 | 需 API Key，免费 2500 次 |

托盘菜单 → 搜索引擎 → 实时切换，无需重启。

> Serper 使用 Google 搜索结果，中文内容质量较高。注册地址：serper.dev，每月免费额度 2500 次，config.json 中填写 `serper_api_key`。

## 切换大模型

修改 `config.json` 的 `active_provider` 字段：

| 供应商 | active_provider 值 | 推荐模型 | 国内直连 |
|--------|-------------------|---------|---------|
| Gemini（默认）| `openai_compatible` | `gemini-2.5-flash` | ❌ |
| DeepSeek | `deepseek` | `deepseek-chat` | ✅ |
| Kimi | `kimi` | `kimi-k2.5` | ✅ |
| 通义千问 | `qwen` | `qwen2.5-vl-max` | ✅ |
| 智谱 GLM | `zhipu` | `glm-4.6v-flash` | ✅ |

## 常见问题

**Q: 按热键没反应？**
A: `keyboard` 库在 Windows 需要管理员权限。右键 `start.bat` → 以管理员身份运行。

**Q: 鉴屎官显示「搜索失败」？**
A: DuckDuckGo 国内无法直连，托盘菜单 → 搜索引擎 → 切换到 Tavily。

**Q: 粘贴头条链接后窗口卡住不动？**
A: 正常现象，Playwright 在后台启动无头浏览器抓取正文，首次约需 15 秒，抓完后自动进入分析。

**Q: 打包后 exe 闪退？**
A: 确认 `config.json` 与 exe 在同一目录，且 `api_key` 已填写。

**Q: 解释/总结也需要联网吗？**
A: 按需联网。遇到近期梗、新产品、不确定的术语时 AI 会自动搜索；内容清晰无需核实时不搜索。追问功能同理，要求搜索或需要最新信息时会自动联网。

**Q: 求出处识别不准确？**
A: 配置 `google_vision_api_key` 开启以图搜图，对冷门漫画/动画效果显著提升。见 [API_KEYS.md](API_KEYS.md)。

## 重建虚拟环境

如依赖有更新或环境损坏：

```bash
rmdir /s /q .venv
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 打包为 exe

```bash
build.bat
```

输出在 `dist\BullshitDetector.exe`。打包后将 `config.json` 放到 exe 同目录下运行。
